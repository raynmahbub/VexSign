Why VexSign

Everything you need, right on device

VexSign combines signing, provisioning, pairing, and installation into a single workflow designed for real iPhone use.

Computer-Free Bootstrap

Start from a compatible iPhone and complete the bootstrap flow without a Mac, Windows PC, cable, or computer-generated pairing file on supported versions.

Secure Pairing

Pairing uses explicit user initiation, validated protocol state, and verified device identity. Unverified peers and invalid records are rejected.

Apple Account Provisioning

Authenticate, handle two-factor verification, register devices, and provision development certificates using VexSign's existing account and signing infrastructure.

Local Signing

IPAs are validated, signed, and verified locally. VexSign checks bundle identity, entitlements, provisioning compatibility, and signature integrity before installation.

Verified Installation

Installation is tracked through explicit states: submitted, confirmed, and launch-verified. VexSign never reports success just because a request was sent.

Open & Auditable

Built in the open on GitHub. The bootstrap, device bridge, signing, and installation logic live in the repository for inspection and contribution.

How it works

From bootstrap to installed app

The on-device flow is designed as a clear sequence of verified steps, with recovery and cancellation at every stage.

01

Prepare the environment

VexSign checks iOS version, device capabilities, Developer Mode, LocalDevVPN connectivity, and required bootstrap dependencies before starting.

02

Pair the device

On supported versions, VexSign establishes a secure local pairing session with explicit user initiation and verifies the resulting pairing record.

03

Authenticate and provision

Sign in with your Apple Account, complete two-factor authentication, select a team, and provision a development signing identity for the target device.

04

Sign locally

VexSign validates the IPA, signs it with the provisioned identity, and verifies the signature, entitlements, bundle identifiers, and checksums.

05

Install and verify

The signed app is installed through the supported device installation mechanism. VexSign confirms the installed bundle and version before reporting success.

FAQ

Common questions

Do I need a Mac or PC?

On supported iOS 27+ devices, the bootstrap flow is designed to work on-device without a Mac, Windows PC, cable, or computer-generated pairing file. Older versions may still require a compatible pairing record or companion flow depending on the available route.

Does VexSign send my Apple Account to a remote VexSign service?

No. Apple Account credentials and private signing keys are not sent to a remote VexSign service. Sensitive credentials are stored using protected storage mechanisms such as Keychain where applicable.

Is this a permanent signing solution?

No. VexSign uses development provisioning and signing. Free Apple Developer accounts have provisioning limits and app expiration rules. VexSign does not claim permanent signing.

What does "verified installation" mean?

VexSign distinguishes between signing completed, signature verified, installation submitted, installation confirmed, and launch verified. A submitted install request is not reported as a successful installation.

Is VexSign open source?

Yes. The VexSign source code is available on GitHub. You can inspect the implementation, review security-sensitive paths, and contribute improvements.
