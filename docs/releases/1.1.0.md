## VexSign 1.1.0

This release distributes the **standalone VexSign app**. The IPA is unsigned:
sign it with your own valid identity and compatible provisioning profile before
installation. No signing certificates, private keys or shared install-server
identity are provided in release attachments.

### Workspace and installation

- A refreshed Home dashboard in the middle of Library / App Store / Home /
  Activity / Settings, with setup guidance, quick actions and workspace search.
- Privacy-aware search and clearer activity, certificate and installation status.
- Separate OTA, paired-device/IDevice and LiveContainer guest routes, with bounded
  pairing imports and a one-guest-at-a-time handoff. Imported/staged guests are
  kept separate from evidence of actual OS installation.
- Device-local installer CA/server identity handling and explicit trust/rotation
  controls; locked or unreadable Keychain data does not silently create a replacement.

### Reliability and safety

- Definite post-sign structural failures block success and library registration.
  Known uncovered retained extensions require a compatible profile or explicit
  removal. Identifier checks read the modified plist, not cached bundle metadata.
  Structural checks are not cryptographic or on-device installation acceptance.

- Safer certificate import/status checks, bounded profile/certificate parsing and
  actionable provisioning/quota failures.
- Archive extraction rejects symlink escapes; raw-DEFLATE decoding requires exact
  input consumption, declared output size and matching CRC.
- Native profile preparation no longer simulates signing or installation success.
  Mutations require separate approvals, real registration results and an early
  CMS capability gate before quota-consuming operations.
- Exact, single-use native key-export grants are invalidated by revocation and
  account lifecycle changes. Key export is not signing or installation authority.

### Experimental features — read before use

The app includes experimental native account and anisette v3 infrastructure,
a pinned upstream provider catalogue, provider-bound device-only ADI storage,
local identity/profile history and a renewal **review queue**. Provider health and
real-device compatibility are not certified by catalogue membership.

**Not complete:** production native CMS promotion, full native-owned-key signing
and device-verified installation, complete remote Apple inventory and scoped
unattended renewal. The default CMS gate remains closed. Local receipts are not
complete portal inventory or signing authority; discovery does not authorize
background mutations.

The VexSign-primary LiveContainer + SideStore integration is a separately tested
**experimental combined-host candidate**, not the stable standalone IPA attached
here. Its bootstrap, dependency/settings/localization packaging changes do not
establish physical-device acceptance. No physical-iPhone or real-provider
acceptance is claimed.

### Download and verify

Use the attached `SHA256SUMS` and `RELEASE.json` to verify the exact artifact and
source commit. Checksums establish integrity, not Apple signing authority.
Simulator/native synthetic tests cannot prove on-device trust, OTA installation,
account provisioning or renewal. Back up important app/container data before testing.
